KAMPUNG NOMBOR AJAIB · نمرح بالأرقام
SK TAMAN SRI MUDA, SHAH ALAM · BAHASA ARAB TAHUN 1

CARA GUNA DI KOMPUTER
1. Buka index.html menggunakan Chrome, Edge atau Firefox.
2. Isi nama murid. Jalankan pengembaraan dengan kekunci anak panah/WASD atau klik lokasi peta.
3. Dekati watak, baca dialog dan pilih 'Bantu saya!' untuk menjawab soalan.
4. Gunakan nota, kad imbas, kuiz, video animasi, lembaran kerja, lencana dan sijil.

CARA GUNA DI TELEFON
1. Muat naik semua fail dalam ZIP ke hosting HTTPS, contohnya GitHub Pages.
2. Buka URL aplikasi menggunakan Chrome atau Safari.
3. Gerakkan watak dengan pad arah di bawah peta atau ketuk lokasi pada peta.
4. Untuk memasang ke skrin utama (jika ditawarkan pelayar), pilih Add to Home Screen / Install App.

CARA TERBIT MENGGUNAKAN GITHUB PAGES
1. Di github.com, cipta repositori baharu, contohnya 'kampung-nombor-ajaib'.
2. Ekstrak ZIP ini. Muat naik index.html, manifest.webmanifest, sw.js, icon-192.png dan icon-512.png ke root repositori.
3. Dalam repositori, buka Settings > Pages. Pilih Deploy from a branch > main > /(root) > Save.
4. Tunggu GitHub memaparkan pautan halaman. Contohnya: https://USERNAME.github.io/kampung-nombor-ajaib/
5. Kongsi URL tersebut kepada murid. Sambungan internet diperlukan ketika membuka buat pertama kali.

FUNGSI
- Dunia peta 2D boleh berjalan dan 4 watak interaktif dengan dialog/soalan.
- 10 flashcard nombor Arab, sebutan TTS melalui suara peranti, nota ringkas.
- Kuiz rawak 10 soalan (perkataan, objek, urutan), bintang dan 6 lencana.
- Muzik latar asli melalui Web Audio (tekan butang ♫ untuk hidupkan).
- Animasi pengajaran nombor terbina dalam serta input pautan YouTube atau video MP4 tempatan.
- Penjana lembaran kerja mengikut tahap (asas/sederhana/pengukuhan); cetak A4 atau pilih Save as PDF.
- Sijil penguasaan boleh dicetak selepas 10 kad dihafal dan kuiz sekurang-kurangnya 8/10.
- Butang 'Murid baharu / set semula' untuk giliran murid lain pada peranti sama.
- Boleh digunakan sebagai PWA jika dihoskan melalui HTTPS, termasuk caching untuk aktiviti asas.

NOTA PENTING
- Aktiviti asas boleh berjalan tanpa Internet, tetapi pautan YouTube memerlukan Internet.
- Suara Arab memerlukan sokongan Text-to-Speech pada peranti. Jika tiada suara Arab, perkataan masih ditunjukkan dalam teks.
- Fail video yang dipilih dari telefon tidak disimpan kekal; pautan YouTube disimpan pada pelayar yang sama.
- Data nama dan pencapaian murid disimpan hanya di pelayar/peranti (localStorage), bukan pangkalan data pusat.
- Untuk kelas di peranti bersama, tekan 'Murid baharu / set semula' antara sesi.
